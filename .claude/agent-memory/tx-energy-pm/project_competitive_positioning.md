**Positioning:** ComparePower sells "find a cheap plan." electric-deals sells "we make sure you never overpay for electricity again." Recurring, personal, trust-driven — a position ComparePower's one-shot comparison UX cannot easily occupy.

**Why this works:** ComparePower is the API source — we cannot beat them on data breadth. We can only win on interpretation, trust, and personalization. The defensible combination is: (personalized usage data from bill upload) + (renewal-alert email relationship) + (REP trust scoring brand) + (long-tail SEO equity). No single layer is a moat; the combination is.

**How to apply:** When evaluating any feature, ask whether it strengthens one of those four layers. Features that don't reinforce at least one are table stakes at best. Avoid features that only improve one-shot comparison — that's ComparePower's home turf. Related: [[project-moat-strategy]], [[project-differentiation-roadmap]].

**Specific competitor weaknesses to exploit:**
- Headline-rate sort hides bill-credit cliffs (every site does this)
- No seasonality modeling — single usage number assumption
- No renewal management — REPs make margin on holdover variable rates, nobody warns users
- No trust layer surfacing PUCT complaints / BBB / billing-accuracy reputation
- Mobile-hostile dense tables
- Spanish-language gap in CenterPoint (Houston) and AEP Central (RGV) territories
